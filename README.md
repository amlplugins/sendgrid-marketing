# @amlplugins/sendgrid-marketing

Native `@sendgrid/client` SDK re-exported under the `@amlplugins` namespace.

> SendGrid Marketing Campaigns — single sends, automations, lists, segments, and senders.

## Install

```bash
npm install @amlplugins/sendgrid-marketing
```

## Use

```ts
import { /* named exports from @sendgrid/client */ } from "@amlplugins/sendgrid-marketing";
// or
import sdk from "@amlplugins/sendgrid-marketing";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
